# Plan Clínico Paz

Aplicación personal de rutina, movilidad y seguimiento inspirada en la estructura y la sensación visual de la referencia original, con un enfoque respetuoso, seguro y adaptado a la situación descrita.

## Qué incluye

- Rutina diaria breve de casa adaptada a escritorio, hombros, parte alta de la espalda, zona torácica y pausas activas.
- Sección de movilidad extra con opción breve/completa y omitido por movimiento.
- Tres sesiones de gimnasio semanales (A/B/C), con ajustes, descanso, variantes y registro de cómo se siente cada ejercicio.
- Seguimiento personal local con localStorage (sin compartir datos personales sensibles).
- Descarga/importación de copias de seguridad y borrado de registros.
- Estilo visual oscuro tipo app móvil/escritorio con pestañas, cards, barra de progreso y temporizador.

## Cómo abrirla

1. Abrir `index.html` en un navegador.
2. O, si se usa GitHub Pages, publicar la rama `main` en la configuración del repositorio.

## Importante

La app es una herramienta de organización y seguimiento; no sustituye una evaluación médica o fisioterapéutica.
